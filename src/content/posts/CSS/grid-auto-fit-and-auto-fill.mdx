## まず動かして確かめる

`repeat(auto-fit, minmax(140px, 1fr))`は「最低140pxを確保しつつ、入るだけ列を作る」
という指定になる。最小幅を変えると列数が変わり、`auto-fill`に切り替えると
要素が足りないときの挙動が変わる。

<Demo id="grid-auto-fit" />

## 違いが出るのは要素が足りないときだけ

コンテナに対して要素の数が十分なら、`auto-fit`と`auto-fill`の結果は同じになる。
違いが出るのは**列を作れる余地があるのに要素が足りない**ときで、

- `auto-fill` … 空のトラックをそのまま残す。だから既存の要素は伸びない
- `auto-fit` … 空のトラックを畳む。畳まれた分の幅を既存の要素が受け取って伸びる

## どちらを使うか

カードの一覧のように**要素を目一杯広げたい**なら`auto-fit`。
グリッドの列位置を保ちたい（少ない要素でも左寄せのまま並べたい）なら`auto-fill`を選ぶ。

```css
/* 余った幅をカードに配りたい */
.cards {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}
```
