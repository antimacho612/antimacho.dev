## メディアクエリとの違い

メディアクエリはビューポートの幅を見るが、コンテナクエリは**親要素の幅**を見る。
同じコンポーネントをサイドバーとメインカラムの両方に置くとき、置かれた場所の幅で
レイアウトを決められる。

## 使い方

親要素に`container-type`を指定し、子要素で`@container`を使う。

```css
.card-container {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 120px 1fr;
  }
}
```

`container-type: inline-size`はインライン方向（横書きなら幅）のみを
コンテナのサイズとして扱う。ブロック方向も見たい場合は`size`を指定するが、
高さが確定していないと機能しないため、通常は`inline-size`で足りる。

## 名前付きコンテナ

コンテナが入れ子になる場合は`container-name`で対象を指定できる。

```css
.layout {
  container-type: inline-size;
  container-name: layout;
}

@container layout (min-width: 800px) {
  .card {
    /* .layout の幅が 800px 以上のときだけ適用される */
  }
}
```
