CSS の `interpolate-size` プロパティと `calc-size()` 関数により、固有キーワード値のアニメーションが可能になった。

## まず動かして確かめる

ホバーした際に、文字の量に合わせて `width: auto` な幅にアニメーションする例。

<Demo id="interpolate-size" />

## プロパティについて

`interpolate-size` プロパティは `auto` や `min-content` などの固有キーワード値サイズと数値間のアニメーションを有効にできるプロパティ。
`root` 要素に以下の指定を追加することで、全体的に有効になる。

```css
:root {
  interpolate-size: allow-keywords;
}
```

<Callout type="warning">
2026年8月時点では、Firefox と Safari で未対応
</Callout>
