記事は`src/content/posts/<カテゴリ>/<スラッグ>.mdx`に置く。
以下のコンポーネントは **import せずにそのまま使える**（記事ページが渡している）。

## Sandbox

HTML / CSS / JSのデモを記事に直接書く。プレビューはiframeで隔離されるので、
デモのCSSが記事のスタイルを壊すことはない。

<Sandbox
  title="ホバーで拡大する"
  height={140}
  html={`<div class="box">hover me</div>`}
  css={`.box {
  display: grid;
  place-items: center;
  width: 160px;
  height: 80px;
  border-radius: 8px;
  background: linear-gradient(135deg, #8b5cf6, #f38ec0);
  color: #fff;
  font-weight: 600;
  transition: transform .3s ease;
}
.box:hover { transform: scale(1.15); }`}
/>

タブでコードを見られるほか、**編集して再実行**もできる。

| props | 既定値 | 説明 |
| --- | --- | --- |
| `html` / `css` / `js` | `''` | デモのソース。空のものはタブに出ない |
| `title` | — | 下に出るキャプション |
| `height` | 自動 | プレビューの高さ(px)。未指定なら中身に追従する |
| `defaultTab` | `preview` | 最初に開くタブ |
| `editable` | `true` | コードの編集を許可する |
| `bleed` | `false` | 本文幅を超えて左右に広げる |

## Demo

行数が増えるデモは`src/demos/<id>/`にファイルとして置き、idで参照する。
エディタの補完と整形が効くので、JSを伴うデモはこちらが書きやすい。

```txt
src/demos/grid-auto-fit/
  index.html   マークアップ（必須）
  style.css    スタイル（任意）
  script.js    スクリプト（任意）
  demo.json    タイトルや高さなどの設定（任意）
```

<Callout type="tip">
ファイルを置くだけで参照できる。index への登録は不要。
`_` で始まるディレクトリは収集対象外なので、テンプレートは `src/demos/_template/` に置いてある。
</Callout>

## Compare

同じマークアップに別々のCSSを当てて並べる。CSSの解説で使う。

<Compare
  title="box-sizingの違い（どちらもwidth: 160px指定）"
  html={`<div class="box">160px + padding</div>`}
  css={`.box {
  width: 160px;
  padding: 16px;
  border: 4px solid #8b5cf6;
  background: rgba(139, 92, 246, .15);
  font-size: 13px;
}`}
  variants={[
    { label: 'content-box（既定）', css: `.box { box-sizing: content-box; }` },
    { label: 'border-box', css: `.box { box-sizing: border-box; }` },
  ]}
/>

## Callout

補足や注意の囲み。`type`は`note` / `info` / `tip` / `warning` / `danger`。

<Callout type="info" title="補足">
`title` を省略すると `type` に応じた既定の文言になる。
</Callout>

<Callout type="warning">
ブラウザ間で挙動が違う話はここに書く。
</Callout>

## Badge

見出しや文中に添える小さなラベル。 <Badge type="tip">tip</Badge> <Badge type="info">info</Badge> <Badge type="warning">warning</Badge> <Badge type="danger">danger</Badge>

## Key / KeyCombination

キーボードのキー。単体なら <Key>Esc</Key>、同時押しは <KeyCombination values={['Ctrl', 'Shift', 'P']} /> と書く。
