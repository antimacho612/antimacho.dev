導入。何の話で、なぜ気にする必要があるのかを 2〜3 行で書く。
前置きが長くなるなら削る。

## まず動かして確かめる

説明より先にデモを置く。短いものは Sandbox に直接書く。

<Sandbox
  title="何が起きているかの一言"
  html={`<div class="box">hello</div>`}
  css={`.box {
  display: grid;
  place-items: center;
  height: 80px;
  border-radius: 8px;
  background: linear-gradient(135deg, #8b5cf6, #f38ec0);
  color: #fff;
  font-weight: 600;
}`}
/>

大きいデモは src/demos/<id>/ に置いて id で参照する。

{/* <Demo id="..." /> */}

## 仕組み

コードと合わせて説明する。コードブロックには言語を指定する。

```css
.box {
  container-type: inline-size;
}
```

ブラウザ差や落とし穴があればここに書く。無ければ丸ごと消す。
</Callout>
